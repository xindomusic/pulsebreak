# 1.3.1 UI palette overhaul — review loops

Branch `feat/ui-palette-131`. Trigger: the 1.3.0 UI read as AI-templated — neon mint slabs and a mauve/purple cast over the 3D. Goal: 9/10 or three review loops, whichever came first.

## Research basis

- Game-UI palette rule (IronEqual): two dark neutrals, two light neutrals, one red for danger, one accent for everything else.
- Destiny: white/graphite minimal panels, color spent almost never. Hades: gold spent like money, literally. Dead Space: restrained hologram lines, conventional danger colors.
- Decision: "aerospace instrument" — warm off-white type on graphite, ONE accent: **signal orange**, the color of the shots you steal. Gold only next to core counts/prices, red only for danger, pale ice only for the player marker and glide. Primary buttons are off-white with ink text; no accent slabs, no glow UI.

## What the loops caught

- Loop 1: the palette file changed but the 3D palette keys were renamed, not repainted (navy steel, pink threat armor, mint literals); eight "primary" buttons in the Hangar; system font; gold spent on combo/best/eyebrows; default Godot sliders.
- Loop 2: focus state impersonated the primary (orange outline + orange text); enemy rings used the player's ice; glide bar photographed empty (staged capture had never called `update_traversal`); upgrade eyebrows and result lines still gold.
- Loop 3 verdict: fixes verified, green/purple/neon fully gone, system coherent. The remaining distance to 9 is bespoke craft — custom iconography, authored card art, combat-frame art direction — not color discipline.
